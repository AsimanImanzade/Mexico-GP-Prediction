# Mexico City GP 2026: win chances dashboard

**Live:** https://asiman-mexico-gp.pages.dev (Cloudflare Pages project `asiman-mexico-gp`)

To publish a new build:

```bash
npm run build && npx wrangler@4.149.0 pages deploy dist --project-name asiman-mexico-gp --branch main
```

A static "pit wall" dashboard for the project's models:

- **Before qualifying:** win chances from the pre-weekend model (XGBoost + logistic regression), precomputed in Python.
- **Set the grid:** drag drivers, type gaps to pole or add grid penalties. The post-qualifying XGBoost model re-scores the grid in the browser. "Load real qualifying" fetches the official result from the Jolpica F1 API.
- **Season stats:** standings, race winners and start-vs-finish per driver for 2014–2026.
- **How reliable is it:** the 2026 backtest, scores against simple rules, the Mexico backtest, and what a grid slot is worth.

No server is involved. The browser runs the exported XGBoost trees and matches the Python model to within 1e-6 on 300 test grids (`src/model/predict.test.ts`).

## On race weekend

Nothing needs publishing for the live parts. Each page load checks the Jolpica API:

- once qualifying is published, the Qualifying clock shows the pole-sitter and visitors land on "Set the grid" with the official result;
- once the race is published, the Race clock shows the winner, a "Race result" tab appears and visitors land on it.

Season stats are static, so adding Mexico to them takes one more publish after the race. The export keeps the prediction frozen: only the stats change.

```bash
cd ..
.venv/bin/python src/fetch_data.py 2014 2026
.venv/bin/python src/build_features.py
.venv/bin/python src/export_dashboard.py
cd dashboard
npm run build && npx wrangler@4.149.0 pages deploy dist --project-name asiman-mexico-gp --branch main
```

## Deploy on Cloudflare Pages

Option 1, from a GitHub repository: Workers & Pages → Create → Pages → connect the repo, then set:

- Root directory: `dashboard`
- Build command: `npm run build`
- Build output directory: `dist`
- Environment variable: `NODE_VERSION` = `22`

Option 2, direct upload: run `npm run build` and drag `dist/` into "Upload assets", or run `npx wrangler pages deploy dist` (needs a Cloudflare login).

`public/_headers` caches the hashed assets for a year and the data files for 10 minutes.
